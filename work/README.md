# Work

The pipeline of work items. The folder an item sits in is its status:

- [`0-ideas.md`](0-ideas.md): undecided ideas, one line each.
- [`1-planned/`](1-planned/): decided, not started.
- [`2-active/`](2-active/): in progress.
- [`3-done/`](3-done/): finished, filed by month.
- [`4-dropped/`](4-dropped/): dropped, with the reason.

Each open item names the items it waits for on a `Blocked by:` line. The table is ordered by it: active items first, then ready ones, those unblocking the most work leading, each blocked item after its blockers. The rules are in [.bc-agent/AGENTS.md](../.bc-agent/AGENTS.md#work-items).
