# Research

Long-form research writeups that are too big for a wiki page: hardware comparisons,
"Jellyfin vs Plex" deep-dives, indexer/usenet-provider evaluations, filesystem
trade-off studies.

## Rules

- One file per investigation; date it.
- When a research file reaches a conclusion, **summarize the durable conclusion back
  into the relevant `project/` page and record the choice as an ADR** in
  `decisions/`. The research file stays as the evidence; the wiki page carries the
  decision.
- Raw/scratch experiments go in `.agent/scratch/` instead (gitignore-able).
